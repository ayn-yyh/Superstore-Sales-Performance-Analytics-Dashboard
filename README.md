# Superstore零售销售绩效分析仪表板
## 项目简介
本项目针对Superstore零售公开数据集，完成销售、客户、产品及盈利能力多维度分析，搭建PowerBI交互式分析看板。

## 使用工具
Excel、Jupyter Notebook、MySQL、Power BI

## 技术栈
Python‑Pandas、SQL、DAX、数据清洗、数据建模、星型模型、数据可视化

## 项目流程
1. 数据获取与数据清洗：使用Pandas完成缺失值、异常值处理；MySQL完成数据查询处理
2. PowerBI构建星型数据模型，编写DAX度量实现各类业务指标计算
3. 制作交互式仪表板，完成客户分群、区域销售、产品盈利分析
4. 输出业务洞察，分析盈利与亏损业务

## 项目文件说明
- data_explorer‑checkpoint.ipynb：Python数据清洗代码
- superstore_query.sql：MySQL查询脚本
- Superstore_Sales_BI_Dashboard.pbix：PowerBI可视化看板文件

## 数据集来源
Superstore公开零售数据集
