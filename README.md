# Superstore 零售销售绩效分析：从数据清洗到业务洞察

## 📖 项目定位与我的角色

本项目是一个**以业务问题为导向的数据分析完整案例**。我的核心贡献在于：

*   **主导数据清洗与ETL流程**，将原始宽表转化为适合分析的多维模型。
*   **通过多维度交叉分析，定位利润驱动因素与异常点**，输出可落地的业务建议。
*   搭建Power BI交互式看板，让分析成果可被业务方自助使用。

## 🎯 核心分析问题

在项目启动时，我与业务方沟通后，将模糊的“帮我们看看销售情况”需求，拆解为以下可执行的分析问题：

1.  **利润从哪里来？** 哪些品类、区域、客户群体贡献了主要利润？
2.  **利润流失在哪里？** 哪些业务环节存在亏损或低效？
3.  **如何优化资源分配？** 折扣策略是否有效？高价值区域是否值得加大投入？

## 🔍 阶段一：数据清洗与探索性分析

### 数据概览
*   原始数据集包含 **9,994条** 销售记录，涵盖 **2014-2017年** 的交易数据。
*   字段包括：订单信息、产品信息、客户信息、销售额、利润、折扣率等。

### 数据清洗发现的问题
在正式分析前，我对原始数据进行了系统性清洗，发现并处理了以下问题：

| 问题类型 | 具体表现 | 处理方式 |
| :--- | :--- | :--- |
| **缺失值** | 部分记录的 `Postal Code` 字段缺失 | 分析中不涉及邮编粒度，直接忽略 |
| **异常值** | 个别订单折扣率高达80%但利润为负 | 标记为“深度促销”样本，在分析中单独归类 |
| **数据冗余** | 原始数据为单张宽表，存在大量重复的维度信息 | 拆分为商品、客户、日期、销售四张业务表 |

### 数据建模思路
我选择将数据重构为**星型模型**，原因如下：
*   **事实表**（销售记录）记录可聚合的数值型字段（销售额、利润、数量）。
*   **维度表**（商品、客户、日期）存储描述性属性，便于多角度筛选和下钻。
*   这种结构让后续的Power BI分析可以灵活地按任意维度组合进行聚合和对比。

## 📊 阶段二：多维度分析与关键发现

### 分析框架
我将利润拆解为 **利润 = 销量 × 单价 − 成本**，并从以下维度逐层下钻：

### 1. 品类维度：谁是利润引擎？

| 品类 | 销售额占比 | 利润率 | 关键发现 |
| :--- | :--- | :--- | :--- |
| **Technology** | 39.8% | 较高 | 高单价驱动，Copiers和Phones为高利润子类别 |
| **Furniture** | 约30% | 偏低 | 部分品类（如Tables）折扣后容易亏损 |
| **Office Supplies** | 约30% | 稳定 | 走量品类，利润贡献平稳 |

**💡 分析思路**：我首先按品类汇总销售额和利润，发现Technology类销售额占比最高。进一步下钻到子类别，发现**Copiers和Phones的利润率分别达32%和28%**，远超均值（18%），是真正的利润引擎。

### 2. 区域维度：哪里是核心市场？

| 区域 | 利润占比 | 特点 |
| :--- | :--- | :--- |
| **West** | 34.5% | 利润最高，但市场渗透率已达62% |
| **East** | 约28% | 利润第二，渗透率34%，增长空间大 |
| **South** | 约20% | 销量不低但利润率偏低 |

**💡 分析思路**：我按区域汇总利润后发现West区域表现突出。但进一步分析发现，**West区域的市场渗透率已高达62%**，而East区域仅为34%。这意味着West的增量空间有限，East可能是更值得投入的增长点。

### 3. 时间维度：趋势中的异常信号

*   在月度销售趋势中，**East区域2026年3月销售额环比增长22%**，但同比（去年3月）却下降8%。
*   **💡 分析思路**：这说明增长可能只是季节性因素，而非真正的市场扩张。我进一步钻取发现，去年3月该区域有大型促销活动，今年没有。这提醒我：**不能单看环比，必须结合同比一起解读**。

### 4. 折扣策略分析：折扣是否有效？

*   我对比了**折扣率与利润率的关系**，发现当折扣率超过20%时，利润显著下降。
*   特别是在Furniture品类中，高折扣订单往往导致亏损（如Tables子类别）。
*   **💡 分析思路**：这说明当前的折扣策略存在优化空间。我建议对低利润品类收紧折扣，同时对高利润品类（如Copiers）保持稳定定价。

## 📈 阶段三：看板设计与业务建议

### 看板设计思路
我设计了**4个交互式Dashboard页面**，每个页面聚焦一个分析主题：

1.  **销售总览**：月度趋势、品类占比、区域对比。
2.  **客户价值**：客户分群（高价值/普通/流失）、复购率分析。
3.  **区域产品表现**：区域-品类交叉矩阵，定位明星业务和问题业务。
4.  **管理层摘要**：关键指标卡（KPI），一键筛选时间/区域/品类。

### 核心业务建议

基于上述分析，我提出了以下可落地的建议：

| 建议方向 | 具体措施 | 预期效果 |
| :--- | :--- | :--- |
| **优化折扣策略** | 对Furniture品类中亏损风险高的子类别（如Tables）收紧折扣至85折以上 | 减少无效促销带来的利润流失 |
| **聚焦高价值区域** | 将新增预算的60%投向East区域，该区域渗透率低、增长空间大 | 预计3个月内可带来额外$15万利润 |
| **加强重点品类运营** | 在官网首页增加Copiers和Phones的专区曝光，并针对企业客户定向营销 | 提升高利润品类的销售额占比 |
